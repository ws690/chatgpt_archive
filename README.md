# ChatGPT NAS Archive

A QNAP Docker Compose project for importing ChatGPT exports and collecting visible chats and downloadable files through a signed-in browser on the NAS.

The collector is best effort. It records partial transcripts and skipped files when it cannot verify complete capture. The browser profile, configuration, and private archive belong on the NAS.

Open the `docs` directory as an Obsidian vault and start at [Index](docs/Index.md).
